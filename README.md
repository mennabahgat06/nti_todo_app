# ToDo App - Flutter UI

Clean Flutter implementation of the screens:
1. Splash Screen
2. Let's Start (Onboarding) Screen
3. Register Screen
4. Login Screen
5. Home Screen (Empty tasks state)

### Folder Structure
- `lib/core/utils/`
  - `app_colors.dart`
  - `app_fonts.dart`
  - `app_assets.dart`
- `lib/screens/`
  - `splash_screen.dart`
  - `lets_start_screen.dart`
  - `register_screen.dart`
  - `login_screen.dart`
  - `home_screen.dart`
- `lib/main.dart`
- `assets/images/`
